# PDF Exporter for GitHub Profile & Markdown Resumes

Универсальный инструмент для экспорта Markdown-документов (и профилей GitHub) в красивый PDF с оформлением GitHub.

## 🚀 Возможности

- **Экспорт в одну непрерывную страницу (по умолчанию)**:
  - Идеально для просмотра на смартфонах и мониторах.
  - Баннер сохраняется в 100% разрешении без обрезки.
  - Таблицы и списки идут единым бесшовным полотном без разрывов.
  - Векторные кликабельные ссылки (Telegram, Email, GitHub).
- **Экспорт в классический A4 (флаг `--a4`)**:
  - Адаптированные стили для печати на бумаге.
  - Защита строк таблиц от разрезания (`break-inside: avoid`).
  - Повтор заголовков таблиц на каждой новой странице.
- **Универсальность**:
  - Подходит для любого Markdown-файла (`.md`) или веб-страницы (URL).

---

## 📦 Установка

Из корня репозитория:
```bash
npm --prefix pdf-exporter install
```
Или перейдя в папку:
```bash
cd pdf-exporter && npm install
```

---

## 🛠 Использование

### Из корня репозитория:
```bash
# 1. Бесшовный PDF в одну длинную страницу (по умолчанию)
npm --prefix pdf-exporter run export-pdf

# 2. Классический постраничный A4 (для печати)
node pdf-exporter/export-pdf.js --a4

# 3. Экспорт любого произвольного файла
node pdf-exporter/export-pdf.js path/to/doc.md output.pdf
```

### Из папки `pdf-exporter/`:
```bash
cd pdf-exporter

# Генерация resume.pdf в корне репозитория
npm run export-pdf

# Постраничный A4
npm run export-pdf -- --a4
```
